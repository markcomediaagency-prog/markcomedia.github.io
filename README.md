# Markco Media Agency — website

Static website (no build step). Files:
- `index.html` — the whole site
- `logo.png`, `favicon.png` — brand images

## Change contact details
Open `index.html`, search for `EDIT YOUR CONTACT DETAILS HERE` and change the email address.

## Publish on GitHub Pages
1. New repository → name `markco-media` → Public → Create.
2. Add file → Upload files → drag in `index.html`, `logo.png`, `favicon.png`, `README.md` → Commit changes.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. After 1–2 minutes your site is live at `https://YOUR-USERNAME.github.io/markco-media/`.
